Forecasting Seasonal Time Series Using Weighted Gradient RBF Network Based Autoregressive Model

Wenjie Ruan*, Quan Z. Sheng, Peipei Xu, Nguyen Khoi Tran, Nickolas J.G. Falkner, Xue Li, Wei Emma Zhang

Time-Series ForecastingData AnalyticsRobust LearningData Quality

Problem

解决的问题

季节序列同时包含周期变化、非线性趋势和局部突变，固定权重自回归难以适应动态模式。

Value

论文结论

在多组季节性数据上降低预测误差，并优于传统 AR、RBF 及其他时间序列基线。

Paper-grounded Academic Summary

论文研究问题与技术路线

主要创新性：把梯度驱动权重更新与 RBF 自回归结合，兼顾周期结构和非线性变化。
学术影响力：在多组季节性数据上降低预测误差，并优于传统 AR、RBF 及其他时间序列基线。该工作推进了噪声、缺失和分布变化条件下的可靠数据建模，并为健康与时空数据应用提供了可复用依据。
