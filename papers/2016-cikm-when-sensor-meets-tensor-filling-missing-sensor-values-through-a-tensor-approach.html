When Sensor Meets Tensor Filling Missing Sensor Values Through a Tensor Approach

Wenjie Ruan*, Peipei Xu, Quan Z. Sheng, Nguyen Khoi Tran, Nickolas J.G. Falkner, Xue Li, Wei Emma Zhang

Sensor DataTensor CompletionMissing-Data RecoveryData Imputation

Problem

解决的问题

这篇论文属于“鲁棒数据分析”方向，核心关注 Sensor Data, Tensor Completion, Missing-Data Recovery, Data Imputation。它要解决的不是单纯提升一个指标，而是在 CIKM 场景下，让模型、数据或感知系统面对真实扰动和任务约束时仍然可用、可评估、可解释。解决时空传感数据缺失和噪声污染问题。针对真实数据采集中的丢包、缺测和异常值。

Value

展示价值

用于展示时，这篇论文可以放在“问题定义 - 方法设计 - 证据评估”的链条中理解。它的价值在于把 Sensor Data 具体化为一个可实验验证的研究问题，并通过 ACM International Conference on Information and Knowledge Management (CIKM)（CCF B, CORE A） 的发表形态呈现该方向的代表性进展。

Technical Route

技术手段

  1. 首先明确任务对象与威胁/噪声来源：围绕 Sensor Data, Tensor Completion 定义输入、输出、约束条件和评价目标。
  2. 利用低秩结构、张量分解或时空相关性恢复完整数据。
  3. 用结构化补全模型提升后续预测、识别和推荐任务的数据质量。
  4. 最后通过与基线方法、消融实验或真实场景案例对比，验证方法在 Sensor Data 上的有效性。

Innovation

创新性

  • 问题视角上，把 Sensor Data 与 Tensor Completion 放到同一实验框架中，避免只做单点性能优化。
  • 技术实现上，将任务结构、模型行为和真实约束结合起来，使方法更贴近可部署系统。
  • 评估方式上，不只看平均准确率，而强调鲁棒性、安全性、可解释性或跨场景泛化表现。
