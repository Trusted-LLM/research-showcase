Problem

解决的问题

真实传感数据同时包含缺失值和异常污染，普通低秩补全容易把离群点吸收到恢复结果中。

Paper-grounded Academic Summary

论文研究问题与技术路线

主要创新性：在统一张量模型中同时处理缺测与污染，兼顾多维结构和对异常值的鲁棒性。
学术影响力：在合成及真实传感数据上提高恢复精度，并能有效定位稀疏异常。该工作推进了噪声、缺失和分布变化条件下的可靠数据建模，并为健康与时空数据应用提供了可复用依据。
