Sensor DataMissing-Data RecoveryTensor CompletionData Analytics

Problem

解决的问题

传感网络丢包会形成跨位置、时间和属性的结构化缺失，逐变量插值不能充分利用多维相关性。

Value

论文结论

Paper-grounded Academic Summary

论文研究问题与技术路线

主要创新性：保持数据的多维拓扑进行联合分解，避免矩阵展开造成的相关结构损失。
学术影响力：在不同缺失率和传感数据集上比常见插值及矩阵方法获得更低恢复误差。该工作推进了噪声、缺失和分布变化条件下的可靠数据建模，并为健康与时空数据应用提供了可复用依据。
