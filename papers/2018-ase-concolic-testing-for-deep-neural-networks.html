Concolic Testing for Deep Neural Networks

Youcheng Sun, Min Wu, Wenjie Ruan, Xiaowei Huang, Marta Kwiatkowska, Daniel Kroening

Concolic TestingDNN VerificationFormal GuaranteesSafety Analysis

Problem

解决的问题

随机或基于梯度的测试难以系统覆盖内部神经元行为，也缺少与传统软件测试相似的目标导向生成机制。

Value

论文结论

原型工具在多种图像网络上有效提升覆盖并发现对抗性或异常行为。

Paper-grounded Academic Summary

论文研究问题与技术路线

主要创新性：首次将 concolic testing 系统引入 DNN，以覆盖准则连接具体执行和符号求解。
学术影响力：原型工具在多种图像网络上有效提升覆盖并发现对抗性或异常行为。该工作扩展了神经网络可证明安全性的适用边界，为高风险模型评测和形式化保证提供了可验证证据。
