鲁棒数据分析：Memory Augmented Hierarchical Attention Network for Next Point-of-Interest Recommendation

Memory Augmented Hierarchical Attention Network for Next Point-of-Interest Recommendation

Chenwang Zheng, Dan Tao, Jiangtao Wang, Lei Cui, Wenjie Ruan, Shui Yu

POI RecommendationData AnalyticsRobust LearningData Quality

Problem

解决的问题

用户签到序列稀疏且具有多尺度时序依赖，短期兴趣和长期偏好难以由单一序列编码器同时捕获。

Value

论文结论

在真实位置社交网络数据上优于多类序列推荐基线，并通过消融验证记忆与层次注意力贡献。

Paper-grounded Academic Summary

论文研究问题与技术路线

主要创新性：首次以 co-attention 显式学习长期记忆和短期时空兴趣之间的动态交互。
学术影响力：在真实位置社交网络数据上优于多类序列推荐基线，并通过消融验证记忆与层次注意力贡献。该工作推进了噪声、缺失和分布变化条件下的可靠数据建模，并为健康与时空数据应用提供了可复用依据。
