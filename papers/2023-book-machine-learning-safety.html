Problem

解决的问题

这篇论文属于“深度神经网络鲁棒性理论”方向，核心关注 Machine Learning Safety, Adversarial Robustness, Verification, Trustworthy AI。它要解决的不是单纯提升一个指标，而是在 Book 场景下，让模型、数据或感知系统面对真实扰动和任务约束时仍然可用、可评估、可解释。关注模型在扰动、分布变化或任务约束下是否稳定。把经验测试推进到带边界或置信度的安全保证。研究对抗扰动如何改变模型决策或系统行为。

Technical Route

技术手段

  1. 首先明确任务对象与威胁/噪声来源：围绕 Machine Learning Safety, Adversarial Robustness 定义输入、输出、约束条件和评价目标。
  2. 建立风险度量、评估算法或认证机制来刻画鲁棒边界。
  3. 使用可达性分析、模型检查、覆盖测试或概率估计进行验证。
  4. 在扰动约束内优化攻击样本或训练防御模型。

Innovation

创新性

  • 问题视角上，把 Machine Learning Safety 与 Adversarial Robustness 放到同一实验框架中，避免只做单点性能优化。
  • 技术实现上，将任务结构、模型行为和真实约束结合起来，使方法更贴近可部署系统。
  • 评估方式上，不只看平均准确率，而强调鲁棒性、安全性、可解释性或跨场景泛化表现。
