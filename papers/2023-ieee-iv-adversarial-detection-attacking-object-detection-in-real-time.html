Technical Route

技术手段

  1. 首先明确任务对象与威胁/噪声来源：围绕 Object Detection, Adversarial Attacks 定义输入、输出、约束条件和评价目标。
  2. 构造白盒、黑盒、稀疏、语义或任务级扰动进行压力测试。
  3. 在扰动约束内优化攻击样本或训练防御模型。
  4. 最后通过与基线方法、消融实验或真实场景案例对比，验证方法在 Object Detection 上的有效性。

Innovation

创新性

  • 问题视角上，把 Object Detection 与 Adversarial Attacks 放到同一实验框架中，避免只做单点性能优化。
  • 技术实现上，将任务结构、模型行为和真实约束结合起来，使方法更贴近可部署系统。
  • 评估方式上，不只看平均准确率，而强调鲁棒性、安全性、可解释性或跨场景泛化表现。
