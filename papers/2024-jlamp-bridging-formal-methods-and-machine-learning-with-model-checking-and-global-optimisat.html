Problem

解决的问题

这篇论文属于“深度神经网络验证”方向，核心关注 Formal Verification, Model Checking, Global Optimisation, Machine Learning。它要解决的不是单纯提升一个指标，而是在 JLAMP 场景下，让模型、数据或感知系统面对真实扰动和任务约束时仍然可用、可评估、可解释。把经验测试推进到带边界或置信度的安全保证。

Value

展示价值

用于展示时，这篇论文可以放在“问题定义 - 方法设计 - 证据评估”的链条中理解。它的价值在于把 Formal Verification 具体化为一个可实验验证的研究问题，并通过 Journal of Logical and Algebraic Methods in Programming（CCF C） 的发表形态呈现该方向的代表性进展。

Technical Route

技术手段

  1. 首先明确任务对象与威胁/噪声来源：围绕 Formal Verification, Model Checking 定义输入、输出、约束条件和评价目标。
  2. 使用可达性分析、模型检查、覆盖测试或概率估计进行验证。
  3. 最后通过与基线方法、消融实验或真实场景案例对比，验证方法在 Formal Verification 上的有效性。

Innovation

创新性

  • 问题视角上，把 Formal Verification 与 Model Checking 放到同一实验框架中，避免只做单点性能优化。
  • 技术实现上，将任务结构、模型行为和真实约束结合起来，使方法更贴近可部署系统。
  • 评估方式上，不只看平均准确率，而强调鲁棒性、安全性、可解释性或跨场景泛化表现。
