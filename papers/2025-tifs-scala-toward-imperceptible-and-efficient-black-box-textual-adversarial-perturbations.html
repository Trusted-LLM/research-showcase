SCALA：低扰动高效率的黑盒文本对抗攻击

SCALA Toward Imperceptible and Efficient Black-Box Textual Adversarial Perturbations

Siqi Sun, Achim D. Brucker, Jia Hu, Xiaowei Huang, Wenjie Ruan*

Black-Box Textual AttacksSynonym SubstitutionLarge Language ModelsAdversarial Attacks

Problem

解决的问题

分数型黑盒文本攻击常需大量查询和同义词替换，既低效又容易破坏可读性；同时缺少对微调 LLM 分类鲁棒性的系统评估。

Value

论文结论

在 7 个数据集、传统 NLP 模型和微调 LLaMA-3.2 上优于多类基线；多数设置下攻击后准确率和扰动率分别低于 5% 与 10%，IMDB 样本约 2.5 秒生成。

Paper-grounded Academic Summary

论文研究问题与技术路线

主要创新性：以 L0/Hamming 距离为核心，将降序攻击与升序回替组成双排序机制，并用批量张量计算兼顾隐蔽性、攻击效果和运行效率。
学术影响力：在 7 个数据集、传统 NLP 模型和微调 LLaMA-3.2 上优于多类基线；多数设置下攻击后准确率和扰动率分别低于 5% 与 10%，IMDB 样本约 2.5 秒生成。该工作为基础模型的安全评测、机制分析与系统防护提供了可迁移的方法和研究依据。
