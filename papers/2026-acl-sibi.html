字典引导的稀疏 Logit 编辑可靠越狱攻击

Dictionary Guided Sparse Logit Editing for Reliable Jailbreak Attacks

Shuaibiao Han, Ruiyang Ni, Changlong Li, Zhiyu Yi, Peipei Xu, Wenjie Ruan

白盒越狱Logit 编辑稀疏干预安全对齐

Problem

解决的问题

许多越狱攻击需要高成本梯度优化，生成的攻击提示也常常不可解释、困惑度高。已有 logit 空间攻击更高效，但可能依赖辅助模型或复杂流水线。

Value

展示价值

这篇论文适合展示 LLM 攻击研究如何从文本表面扰动深入到解码分布与安全对齐机制。

Technical Route

技术手段

  1. 提出 SIBI：白盒、推理时、无需梯度和辅助模型的稀疏 logit 编辑攻击。
  2. 离线挖掘 tokenizer 对齐的惩罚/奖励 token 字典，识别拒答路径和服从路径中的关键语义索引。
  3. 推理时只修改少量 pre-softmax logits，并用温度一致缩放和混合范数 trust region 保持流畅性。

Innovation

创新性

  • 用小字典和稀疏干预替代长时间 prompt 优化，显著降低时间和显存开销。
  • 把越狱机制定位到拒答 token 的根部抑制，解释性强于黑盒字符串攻击。
  • 揭示仅靠内部 hardening 不足，外部语义审计对抵御这类攻击更有效。
