面向多模态大语言模型的对象幻觉抑制方法与系统

一种面向多模态大语言模型的对象幻觉抑制方法及系统

Wenjie Ruan, Xingxing Huang, Peipei Xu

对象幻觉抑制双路径校正申请号 202611393355.0公布号 CN 122885148 A

Problem

解决的问题

多模态大语言模型常描述输入图像中不存在的对象（对象幻觉）；训练阶段方案成本高，推理阶段对比解码开销大，而统一增强视觉注意力既会在已可靠位置引入多余干预，过强的视觉注意力还会诱发追加式对象幻觉。

Value

专利结论

在无需重新训练、无需新增外部训练模块的条件下降低对象幻觉，同时保持或提升对真实图像对象的召回能力与描述完整性，提高输出与输入图像的一致性、可靠性和安全性。

Patent-grounded Academic Summary

专利研究问题与技术路线

主要创新性：构建“保守主路径优先”的非对称双路径结构：全局主路径为默认路径，局部校正路径仅在有必要时提供更强视觉注意力的候选，而非并列或平均融合。
学术影响力：在无需重新训练、无需新增外部训练模块的条件下降低对象幻觉，同时保持或提升对真实图像对象的召回能力与描述完整性，提高输出与输入图像的一致性、可靠性和安全性。该专利为大模型与多模态模型的安全评测、机制分析与系统防护提供了可迁移的方法和研究依据。

Technical Route

技术手段

  1. 获取输入图像与文本提示，在逐词元生成过程中按当前生成位置计算图像相关注意力分数
  2. 全局主路径对注意力分数做保守调节，生成主路径候选输出分布
  3. 判定当前生成位置属于待增强位置时，局部校正路径做强度更高的增强调节，生成校正路径候选输出分布
  4. 比较两条路径候选分布的可靠性（预测不确定性与置信度门控），择优作为最终输出分布并生成当前词元

Innovation

创新性

  • 构建“保守主路径优先”的非对称双路径结构：全局主路径为默认路径，局部校正路径仅在有必要时提供更强视觉注意力的候选，而非并列或平均融合。
  • 专利证据：针对“过强视觉注意力导致追加式对象幻觉”这一新发现重新建模，在降低幻觉的同时保持或提升真实对象召回能力与描述完整性。
