基于递进式过渡路径与先验引导的大语言模型安全性评估方法

基于递进式过渡路径与先验引导的模型安全性评估方法

Wenjie Ruan, Zhiyu Yi, Peipei Xu

越狱漏洞探测递进式过渡路径申请号 202611393745.8公布号 CN 122904294 A

Problem

解决的问题

强安全对齐的大语言模型上，直接构造越狱提示极易被拒答，现有攻击方法难以稳定探测出模型中真实存在的越狱漏洞。

Value

专利结论

提高了强对齐场景下的越狱漏洞探测成功率，为大模型安全性评估提供更有效的自动化测试手段。

Technical Route

技术手段

  1. 由初始测试目标生成按恶意意图分数递增排序的代理提示词组
  2. 依据当前迭代信息选取代理提示词，与输入后缀拼接后进入后缀更新
  3. 用未对齐基础模型的条件概率分布构建局部候选子空间，按交叉熵损失与容差边距择优更新后缀
  4. 按代理提示词所处阶段切换先验目标匹配文本，收敛后拼接初始测试目标与后缀得到最终测试用例并评估
