基于预测失谐后缀优化与图像短语注入的 VLM 越狱

Jailbreaking Vision-Language Models via Dissonance-Guided Suffix Optimization and Image-Phrase Injection

Jiacheng Pi, Zhiguo Yang, Xingxing Huang, Dongsheng Xu, Ruizhi Zhong, Wenjie Ruan*

VLM 越狱多模态攻击预测失谐图像短语注入

Problem

解决的问题

VLM 同时接收图像和文本，攻击面比纯文本 LLM 更大。已有后缀优化方法在离散 token 空间中容易陷入局部最优，图像扰动方法跨模型迁移性又较弱。

Value

展示价值

这篇论文展示了多模态安全的关键差异：攻击不只发生在文本，也可以利用图像里的可读语义和模型跨模态融合机制。

Technical Route

技术手段

  1. 用目标模型和未对齐 guide model 的预测差异识别被安全对齐压制的 token，作为后缀搜索信号。
  2. 联合优化文本 adversarial suffix 与嵌入图像中的 phrase 内容/呈现方式，利用 VLM 的跨模态敏感性。
  3. 在 MiniGPT-4、InstructBLIP、LLaVA 以及 GPT-4o-Mini、Gemini、Qwen-VL 等黑盒模型上评估迁移效果。

Innovation

创新性

  • 用 predictive dissonance 替代粗糙梯度近似，为离散后缀搜索提供更直接的安全对齐信号。
  • 把文本后缀和图像短语注入组合成协同攻击，提升多模态越狱强度。
  • 证明开源 VLM 上优化得到的攻击可以迁移到商业黑盒 VLM，暴露现实风险。
