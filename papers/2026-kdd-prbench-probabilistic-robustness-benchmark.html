PRBench：标准化概率鲁棒性基准

PRBench A Standardized Probabilistic Robustness Benchmark

Yi Zhang, Zheng Wang, Zhen Chen, Wenjie Ruan, Qing Guo, Siddartha Khastgir, Carsten Maple, Xingyu Zhao

Probabilistic RobustnessRobustness BenchmarkAdversarial TrainingGeneralization Error

Problem

解决的问题

概率鲁棒性训练缺少统一协议，既无法公平比较风险训练与对抗训练，也缺少同时覆盖准确率、AR、PR、泛化误差和效率的系统证据。

Value

论文结论

基准覆盖 7 个数据集、10 类模型架构和 229 个训练模型；结果揭示两条权衡前沿：AT 同时提升 AR 与 PR 但牺牲干净准确率和泛化，而 PR 定向方法保留更高准确率与更低泛化误差但降低 AR。

Paper-grounded Academic Summary

论文研究问题与技术路线

主要创新性：建立首个专门面向概率鲁棒性的标准化基准，把经验评测、泛化理论和可扩展排行榜连接为统一研究基础设施。
学术影响力：基准覆盖 7 个数据集、10 类模型架构和 229 个训练模型；结果揭示两条权衡前沿：AT 同时提升 AR 与 PR 但牺牲干净准确率和泛化，而 PR 定向方法保留更高准确率与更低泛化误差但降低 AR。该工作深化了对鲁棒性定义、风险度量与学习动态的理论理解，为后续验证和鲁棒学习研究提供了分析工具。

Technical Route

技术手段

  1. 统一形式化经验风险、对抗训练、风险训练与混合训练目标
  2. 在一致攻击、概率指标、泛化误差和训练时间协议下评测 13 种方法
